# GTag6

Arduino-библиотека для работы с электронным ценниковым дисплеем **SES-imagotag G-Tag 6** на микроконтроллерах ESP32 и ESP8266.

Библиотека использует собственный драйвер дисплея и framebuffer в памяти микроконтроллера. Для рисования используется совместимый с `Adafruit_GFX` интерфейс.

## Возможности

* Поддержка дисплея SES-imagotag G-Tag 6
* Разрешение дисплея **256 × 128 пикселей**
* Чёрно-белый вывод
* Полный framebuffer размером 4096 байт
* Рисование пикселей, линий, прямоугольников и текста
* Совместимость с API `Adafruit_GFX`
* Поддержка пользовательских шрифтов `Adafruit_GFX`
* Автоматическое обновление дисплея
* Возможность ручного обновления
* Аппаратный RESET дисплея
* Генерация необходимого DisplayCLK
* Поддержка ESP32
* Поддержка ESP8266

# Дисплей

G-Tag 6 имеет разрешение:

```text
256 × 128 пикселей
```

Framebuffer:

```text
256 × 128 / 8 = 4096 байт
```

Дисплей является монохромным:

| Значение | Цвет   |
| -------: | ------ |
|      `0` | Белый  |
|      `1` | Чёрный |

В библиотеке доступны константы:

```cpp
GTAG6_BLACK
GTAG6_WHITE
```

---

| Пин G-Tag 6 | Функция             | Подключение к ESP32 |
| :---------: | ------------------- | :-----------------: |
|    **S1**   | DisplayCLK ≈ 29 кГц |       GPIO 17       |
|    **4**    | 1 Hz, выход         |          —          |
|   **S10**   | DIO                 |       GPIO 23       |
|   **S11**   | CLK                 |       GPIO 18       |
|    **7**    | CS                  |        GPIO 5       |
|    **8**    | RES / RESET         |       GPIO 16       |
|   **GND**   | GND                 |         GND         |


* На ESP8266 необходимо выбрать реальные доступные GPIO конкретной платы и передать их в конструктор библиотеки.

# Создание объекта

Для ESP32:

```cpp
GTag6 display(23, 18, 5, 16, 17);
```

Порядок параметров:

```cpp
GTag6(DIO, CLK, CS, RESET, DISPLAY_CLK);
```

Например:

```cpp
GTag6 display(
    23,  // DIO
    18,  // CLK
    5,   // CS
    16,  // RESET
    17   // DisplayCLK
);
```

---

# Инициализация

В `setup()` необходимо вызвать:

```cpp
display.begin();
```

Пример:

```cpp
void setup() {
    display.begin();
}
```

# Обновление дисплея

После изменения framebuffer необходимо передать его содержимое в дисплей.

Для ручного обновления:

```cpp
display.refresh();
```

Пример:

```cpp
display.fillScreen(GTAG6_WHITE);

display.setTextColor(GTAG6_BLACK);
display.setTextSize(2);
display.setCursor(20, 30);
display.print("Hello!");

display.refresh();
```

---

# Автоматическое обновление

Библиотека поддерживает автоматическое периодическое обновление:

```cpp
display.setAutoRefresh(5000);
```

Значение задаётся в миллисекундах.

Например:

```cpp
display.setAutoRefresh(5000);
```

означает обновление примерно каждые **5 секунд**.

В `loop()` при этом необходимо регулярно вызывать:

```cpp
display.tick();
```

Пример:

```cpp
void loop() {
    display.tick();

    // остальной код программы

    delay(5);
}
```

Это особенно важно для стабильной работы G-Tag 6.

---

# Ручной режим

Если автоматическое обновление не требуется:

```cpp
display.setAutoRefresh(0);
```

После изменения изображения:

```cpp
display.refresh();
```

# Ячейки таблицы

Библиотека поддерживает вывод информации в виде таблицы с помощью `GTag6Table`.

Это удобно для:

* датчиков;
* погодных станций;
* мониторинга компьютера;
* информационных панелей;
* часов;
* показаний температуры;
* различных UI.

Пример концепции:

```cpp
GTag6Table table(...);
```

После создания таблицы можно задавать содержимое отдельных ячеек через:

```cpp
table.setCell(...);
```

Точные размеры и количество столбцов зависят от конфигурации таблицы.

# Полный минимальный пример

```cpp
#include <Arduino.h>
#include <GTag6.h>

GTag6 display(23, 18, 5, 16, 17);

void setup() {
    Serial.begin(115200);

    display.begin();

    display.setAutoRefresh(5000);

    display.fillScreen(GTAG6_WHITE);

    display.setTextColor(GTAG6_BLACK);
    display.setTextSize(2);

    display.setCursor(20, 30);
    display.print("G-Tag 6");

    display.setCursor(20, 60);
    display.print("Hello!");

    display.refresh();
}

void loop() {
    display.tick();

    delay(5);
}
```

# Важная особенность G-Tag 6

G-Tag 6 отличается от обычных SPI-дисплеев.

Недостаточно просто передавать данные по `CLK/DIO/CS`. Дисплею также необходим отдельный сигнал **DisplayCLK**.

Для ESP32 в используемой конфигурации:

```text
GPIO17 → DisplayCLK
```

Частота:

```text
≈ 29 кГц
```

Этот сигнал должен продолжать работать во время работы дисплея.

Кроме того, для стабильной работы библиотеки используется периодическая повторная инициализация дисплея.
